# Place Links into Worksets

## Description

This Revit script creates a workset for each Revit link and assigns the link type and all its instances to that workset. Existing worksets are reused, and nested links are skipped.

## How to use

1. Open a workshared Revit project.
2. Run `place-links-into-worksets.py` in Revit.
3. Enter a workset name prefix and click **OK**.
4. Review the results after the script finishes.
