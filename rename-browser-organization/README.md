# Rename Browser Organization

## Description

This Revit script renames built-in browser organization schemes. It is especially useful after changing a project's language, when the default organization names remain in the previous language. These names cannot be changed through the Revit interface, but they can be renamed through the API.

## How to use

1. Run `rename_browser_organization.py` in RevitPythonShell.
2. Enter the desired names in the **New Name** column. Leave a field empty to keep its current name.
3. Click **Rename** to apply the changes, or **Cancel** to close the window without changing anything.
